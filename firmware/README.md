# firmware/

Kode Arduino/ESP32. Letakkan sketch di `firmware/tomato_sorter/` (nama file `.ino` harus sama dengan nama foldernya: `tomato_sorter.ino`).

Wajib mengikuti `docs/PROTOCOL.md` dan state machine di `docs/ALUR_ALAT.md`.
Konstanta waktu dan pin dikumpulkan di bagian atas sketch (atau `config.h`), bukan tersebar di kode.
