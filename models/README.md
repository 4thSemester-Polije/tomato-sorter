# models/

Model Keras hasil training (`ripeness_resnext101.keras` dan
`defect_resnext101.keras`) serta metadata dan laporan evaluasi JSON. Model
tidak di-commit secara default (lihat `.gitignore`). Model final untuk demo
boleh di-commit manual dengan `git add -f models/<nama>`.

Prosedur training, evaluasi, dan API ada di `docs/ML_RESNEXT101.md`.
